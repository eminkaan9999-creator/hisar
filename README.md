# Çelik Börü

[Oyunu aç](https://eminkaan9999-creator.github.io/hisar/)

Ana giriş, son tasarım değişikliğinden önceki v119 tank dünyasını, modelleri, dokuları ve menüleri kullanır. Cihazların bu içeriğe güncellenebilmesi için yayın numarası 126 olarak korunur.

## Doğrulama

- `node --test experience/*.test.cjs`
- `node iti/iti-assistant.test.cjs`
- `node scripts/restore-games-browser.cjs` eski kurulumdan geçişi, kayıtların korunmasını ve tankın açılıp hareket etmesini Chromium üzerinde denetler.
- `node scripts/experience-browser.cjs` masaüstü ve mobil ekranlardaki oyun akışlarını denetler.
